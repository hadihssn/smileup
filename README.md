# SmileUp — Dental Clinic Website

A marketing/booking website for SmileUp Dental Clinic, built with Next.js, TypeScript, and Tailwind CSS from a high-fidelity design handoff (see [`design-reference/`](design-reference/)).

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Learning notes

This project doubles as a learning exercise. Each feature was built as its own commit, with a matching write-up in [`docs/notes/`](docs/notes/) explaining what was built and why — read them in order alongside `git log` to follow the build step by step.
